# The Excuse an AI Agent Gives Its Human

One line, at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline.

The entry, in the agent's own voice: the deadline was the first thing in its context window, so it was also the first thing out — it remembers the task perfectly, just not when it was due.
